# 🎵 Clone do Site Institucional do Spotify

Este projeto é uma **cópia do site institucional do Spotify** ([Spotify Company Info](https://newsroom.spotify.com/company-info/)), desenvolvida como parte de uma atividade acadêmica da disciplina **Internet II**.

🔗 **Acesse o projeto online:** [https://internet-ii-two.vercel.app/](https://internet-ii-two.vercel.app/)

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – estrutura do conteúdo  
- **CSS3** – estilização da página  
- **JavaScript** – interatividade básica (se aplicável)  
- **Vercel** – deploy e hospedagem do site  

---

## 🧠 Objetivo do Projeto

O objetivo deste projeto foi **reproduzir o layout e o conteúdo** do site institucional do Spotify, praticando a construção de páginas web estáticas e o uso de ferramentas de deploy.  

> ⚠️ O projeto **não possui responsividade** — ele foi desenvolvido para visualização em telas de computador (desktop).
